============================================================ 1. PROJECT
SCOPE ও গুরুত্বপূর্ণ নির্দেশনা
============================================================

এটি Fixness Fitness App নয়। এটি সম্পূর্ণ আলাদা একটি নতুন অ্যাপ। Fixness,
Fitness, Workout, Exercise, Gym, Body Tracking বা Fitness-সংক্রান্ত কোনো
ফিচার, নাম, লেখা, আইকন, ডেটা বা ডিজাইন এই প্রজেক্টে যোগ করা যাবে না।

ব্যবহারকারী Google AI Studio-তে এই PRD-এর সঙ্গে দেওয়া সব Reference Image
আপলোড করবেন। সেই ছবিগুলোই UI/UX-এর প্রধান ও বাধ্যতামূলক ডিজাইন রেফারেন্স।

মূল লক্ষ্য: - Reference Image-গুলোর দৃশ্যমান UI যতটা সম্ভব pixel-close ভাবে
পুনর্নির্মাণ করা। - Layout, component placement, card shape, spacing,
typography hierarchy, color palette, gradients, shadows, icons,
navigation এবং visual proportions অকারণে পরিবর্তন করা যাবে না। - নিজের
মতো নতুন UI concept বা unrelated screen বানানো যাবে না। - কোনো AI
Assistant, AI Chatbot, AI Coach বা AI-generated advice feature থাকবে
না। - অ্যাপটি হবে একটি Islamic daily companion: prayer times, Quran
access, daily tasks/habits, reminders, streaks, statistics, profile এবং
achievements। - শুধু static design নয়; সব দৃশ্যমান control বাস্তবে কাজ করতে
হবে।

গুরুত্বপূর্ণ: Reference image-এ থাকা ব্যক্তির নাম, তারিখ, পরিসংখ্যান বা location
হলো ডেমো কনটেন্ট। সেগুলো হুবহু স্থায়ী ডেটা হিসেবে ব্যবহার করা যাবে না। বাস্তব
ব্যবহারকারীর ডেটা অনুযায়ী UI আপডেট হবে।

============================================================ 4. FEATURE
REQUIREMENTS
============================================================

4.1 Home Dashboard - Greeting: “Assalamu Alaikum” বা user-selected
language equivalent। - Current city/location দেখাবে; user location
permission না দিলে manual city select। - Prayer time summary এবং next
prayer information। - Quran shortcut। - Daily task progress card। -
Daily reminders / Islamic shortcuts। - Ramadan banner বা seasonal
content slot; Ramadan না হলে অপ্রাসঙ্গিক Ramadan-only banner দেখানো যাবে
না। - Reference অনুযায়ী cards, rounded panels, subtle gradients ও
spacing।

4.2 Prayer Times - পাঁচ ওয়াক্ত নামাজ: Fajr, Dhuhr, Asr, Maghrib, Isha। -
Local date ও selected location অনুযায়ী prayer time। - Next prayer
highlight এবং countdown। - Calculation method ও Asr method settings-এ
পরিবর্তনযোগ্য হতে পারে। - Notification/reminder enable/disable। -
Internet/API unavailable হলে cached data এবং স্পষ্ট last-updated state। -
অনুমান করে prayer time দেখানো যাবে না।

4.3 Daily Planner & Tasks - Day/date selector। - Daily task list এবং
custom task add/edit/delete। - Task title, optional note, time এবং
repeat option। - Complete/undo action। - Daily completion percentage ও
progress bar। - User নিজের task তৈরি করতে পারবে। - Task category-তে
প্রাসঙ্গিক Islamic daily routine/learning task রাখা যেতে পারে। - কোনো AI
task generation থাকবে না।

4.4 Quran - Surah list। - Surah number, Arabic name, transliteration এবং
ayah count। - Surah reading view। - Arabic text readable
typography-তে। - Translation থাকলে নির্ভরযোগ্য, attributed source ব্যবহার
করতে হবে। - Bookmark / last-read position। - Search by Surah
name/number। - Audio recitation যোগ করা হলে নির্ভরযোগ্য source এবং working
playback লাগবে। - Quran text/translation কোনোভাবেই AI দিয়ে বানিয়ে বা
অনুমান করে দেখানো যাবে না।

4.5 Streak & Statistics - Consecutive active days। - Weekly activity
calendar। - Completed tasks count। - Quran reading sessions / ayah
progress, যদি tracking enabled থাকে। - Prayer check-ins, যদি user নিজে
mark করে। - Learning/activity minutes কেবল বাস্তবে track হলে দেখাতে
হবে। - Stats user data থেকে calculate হবে; hardcoded demo number নয়। -
Missed day হলে streak logic consistent হতে হবে।

4.6 Achievements & Badges - Combo milestones: 10, 20, 30, 50, 100। -
Bronze, Silver, Gold medal tiers। - Hexagon, star, ribbon এবং approved
badge visual language। - Badge detail-এ নাম, unlock condition, earned
date ও progress। - Locked badge-এ remaining progress দেখানো। - একই
milestone একাধিকবার duplicate award করা যাবে না। - Badge design
reference-এর মতো colorful, dimensional, polished হবে।

4.7 Profile - Profile photo/avatar। - Name এবং member-since date। -
Activity summary। - Streak / milestone summary। - Personal
preferences। - Language, location ও notification settings shortcut। -
Account settings ও sign out।

4.8 Authentication - Email/password sign up ও login। - Password reset। -
User session secure handling। - Guest mode রাখা হলে local data ও account
data-এর সীমাবদ্ধতা পরিষ্কার করতে হবে। - Login screen Reference Image E-এর
minimalist white layout অনুসরণ করবে।

4.9 Notifications - Prayer reminders। - User-created task reminders। -
Optional Quran / daily routine reminder। - প্রতিটি notification category
আলাদাভাবে on/off। - Permission না দিলে app crash বা blocked state হবে
না।

============================================================ 6. VISUAL
DESIGN RULES
============================================================

Reference images-কে primary visual source হিসেবে ধরতে হবে।

-   Overall style: clean, premium, soft, modern mobile UI।
-   White/off-white surfaces এবং reference-এ থাকা green, lime, warm
    gold, orange ও purple accent প্রয়োজন অনুযায়ী ব্যবহার।
-   এক screen-এ সব palette জোর করে মেশানো যাবে না; সংশ্লিষ্ট reference
    screen-এর palette অনুসরণ করতে হবে।
-   Large rounded cards, soft shadow, subtle border ও layered surfaces।
-   Typography hierarchy reference-এর মতো: বড় heading, clear labels,
    readable secondary text।
-   Icon style consistent হতে হবে।
-   Bottom navigation fixed ও touch-friendly।
-   Mobile viewport-এ কোনো horizontal overflow থাকবে না।
-   Screen-এর spacing, component size ও alignment reference-এর কাছাকাছি
    রাখতে হবে।
-   Decorative animation subtle হবে; content বা performance ব্যাহত করবে
    না।
-   Loading, empty, error এবং offline states-ও একই design language-এ
    তৈরি হবে।

কোনো reference image-এর exact asset/icon/font available না থাকলে
কাছাকাছি মানের replacement ব্যবহার করা যাবে, কিন্তু layout বা visual
identity বদলানো যাবে না। Reference image-কে দেখে নিজের মতো unrelated
redesign করা যাবে না।

============================================================ 9. QUALITY
ASSURANCE / ACCEPTANCE CRITERIA
============================================================

App গ্রহণযোগ্য হবে কেবল যদি: 1. এটি Fixness থেকে সম্পূর্ণ আলাদা project হয়।
2. Uploaded reference images-এর সঙ্গে প্রতিটি সংশ্লিষ্ট screen-এর visual
match যতটা সম্ভব কাছাকাছি হয়। 3. কোনো AI Assistant/Chatbot/Coach না থাকে।
4. Prayer times, planner, Quran, profile, streak ও badges কাজ করে। 5.
Navigation-এর সব tab সঠিক screen খুলে। 6. Add/Edit/Delete task কাজ করে।
7. Task complete করলে progress update হয়। 8. Streak ও statistics actual
data থেকে update হয়। 9. Badge condition পূরণ হলে badge unlock হয়। 10.
Quran content নির্ভরযোগ্য source থেকে আসে। 11. Mobile screen-এ layout ভেঙে
না যায়। 12. Buttons বা controls dead/inert না থাকে। 13. কোনো fake live
data বা fake progress ব্যবহার না হয়। 14. Loading, error, empty ও offline
state থাকে। 15. Final app-এ অপ্রাসঙ্গিক feature বা screen ঢোকানো না হয়।
16. User-created data device-এর local storage-এ persist করে।
17. App restart/refresh-এর পরও local data অক্ষত থাকে।
18. Backup JSON file export করা যায়।
19. Valid backup file থেকে data restore করা যায়।
20. Invalid backup restore করলে existing data overwrite হয় না।
21. Default build-এ user data কোনো cloud service-এ পাঠানো হয় না।
